# Gear Skill Instructions (PCE-Studio Only)

When the `/gear` skill or command is invoked in pce-studio:

1. **Start geargfx MCP Server**: Initialize and start the `geargfx` MCP server.
2. **Visual Image Feedback**: For every code update and subsequent build command executed, automatically capture/display an image showing the visual changes brought by the update in pce-studio.
